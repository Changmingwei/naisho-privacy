# naisho-privacy

Naisho（私话）的隐私政策，用 GitHub Pages 托管，地址：
**https://changmingwei.github.io/naisho-privacy/**

这个地址填在两个地方：
- App Store Connect → App 信息 → Privacy Policy URL
- App Store Connect → TestFlight → 测试信息 → Privacy Policy URL

`index.html` 是发布出去的那一份。**记录源在私有仓库 `Changmingwei/AirBuddy` 的
`docs/privacy-policy.md`**：改了任何一边，另一边要跟着改。内容按 app 的真实数据行为写，
改了数据行为（尤其是诊断上传）必须同步改这一页。
